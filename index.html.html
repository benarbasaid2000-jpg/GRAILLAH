⭐ Activer les avis Google

Google n'autorise à afficher ses avis qu'en direct, avec une clé personnelle (gratuite jusqu'à un certain nombre d'utilisations par mois).

  1. Va sur console.cloud.google.com et connecte-toi avec ton compte Google.
  2. Crée un projet, puis active Maps JavaScript API et Places API (New). Google demande une carte bancaire pour vérifier le compte.
  3. Dans « Identifiants », crée une clé API. Pour la protéger, limite-la à ces deux API et à l'adresse de ton site.
  4. Colle la clé ci-dessous.
